## A. 合约和机器

| # | 情况 | 实际情况 | 状态 |
|---|---|---|---|
| 1 | 机器或合约已过期 | "Show expired service items" 默认开着，照样开单，画面没有提示 | 已确认 |
| 2 | 这个月中途过期 | 照整个月收，完全没有按天算；预收租金的机器最后一个月没有租金行 | 已确认 |
| 3 | 过期那个月到下个月初还没开单 | 合约自动变 Inactive（"Expired (auto)"），从 Run 和 Overdue 消失 | 已确认 |
| 4 | 合约或机器设了 Inactive | 马上消失，Inactive 日期没用；开了 "Show inactive" 会出现，但没有标记（SC 000000017） | 已确认 |
| 5 | 机器自己的到期日比合约早 | 照样开单，没有标记。ATPTEST 有 347 台（例如 SC-000326 / CSSI 00000063，30/04/2026 到期）。反过来，机器比合约晚到期的，会跟着合约被自动 Inactive | 已确认 |
| 6 | 合约还没开始（ATP-11） | 不列出，没有提示 | 正常 |
| 7 | 选了开始日期之前的月份（但开始日期已经过了） | 一般合约：显示红色 Overdue，**可以开出开始前的月份**，单上会写 "(-1/36)"。预收租金的合约有挡 | 部分确认 |
| 8 | 机器中途加入 | 加入之前的月份也会出现（SC 000000007 的机器 22/07 才开始，6 月照样列出）。只有"一张单"的合约会整张 Waiting；每台机器一张单的只影响自己。预收租金一次收 2 个月是 ATP-10 的设计 | 部分确认 |
| 9 | 合约没有机器，或机器没有 counter | 什么都不显示（ATPTEST：3 张合约没有机器，185 张没有 counter） | 已确认 |
| 10 | Bill-from 之前的月份 | Take 过来、link 有效的合约整张不在 Run 里，所以不影响。用 Billing Start 设定的合约，之前的月份还是显示红色、可以开 | 部分确认 |
| 11 | 故意 Skip 的月份 | 日视图照样显示红色、可以开；不过 Skip 只能在 Inter-Billing 做，目前 0 笔 | 部分确认 |
| 12 | "合约完成"、"还剩几个月" | Run 完全不用，只有 Inter-Billing 有，所以两个画面的说法会不一样 | 已确认 |
